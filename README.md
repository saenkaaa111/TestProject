Небольшой пет-проект, который представляет собой REST API сервис для управления задачами с асинхронной обработкой. Сервис позволяет создавать задачи и проверять их статус.

Проект реализован с использованием трехслойной архитектуры:
- Controller Layer (TaskController) - обрабатывает HTTP запросы и возвращает ответы.
- Business Layer (TaskService) - содержит бизнес-логику приложения.
- Data Layer (TaskRepository) - отвечает за взаимодействие с базой данных.
